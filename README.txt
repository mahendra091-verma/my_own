MUNNA KIRANA STORE & BUILDING WORKS WEBSITE

Files:
- index.html
- css/style.css
- js/script.js

RUN:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html with the VS Code Live Server extension (recommended), or open it in a browser.

IMPORTANT SETUP BEFORE PUBLISHING:
1. Phone number: the number supplied earlier (44545455656) has 11 digits. Verify the correct phone number before publishing.
2. WhatsApp: open js/script.js and set BUSINESS_WHATSAPP_NUMBER to the verified number in international format, digits only. Example format for India: 919876543210.
3. Grocery prices are sample placeholders, not verified shop prices. Update them in the Admin panel.
4. Gate, door and window images are illustrative online reference photos, not actual photographs of Munna's completed work. Replace them with real business photos when available.
5. Google Maps embed searches for Gram Heerapur, Panna, Madhya Pradesh; verify the pin before publishing.
